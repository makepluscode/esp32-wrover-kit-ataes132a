# 예제 51: 잠금 후 Zone 0 읽기 전용 테스트

이 예제는 칩이 잠긴(`LOCKED`) 상태에서 Zone 0이 읽기 전용으로 안전하게 보호되고 있는지 확인합니다.

## 테스트 내용
1. **읽기 테스트**: Zone 0 (0x0000)에서 16바이트를 읽어옵니다. (성공해야 함)
2. **쓰기 테스트**: 동일한 위치에 데이터를 쓰려고 시도합니다. (칩 정책에 의해 거부되어야 함)

## 실행 방법
```powershell
.\build.ps1 51 all
```

## 기대 결과
- 읽기 작업은 성공하여 저장된 데이터가 출력됩니다.
- 쓰기 작업은 실패하며, 리턴 코드로 `0x04` 또는 `0x08`이 반환됩니다.

## 실행 결과
```text
========================================
예제 51: 잠금 후 Zone 0 읽기 전용 테스트
========================================

[Step 1] Zone 0 (0x0000) 16바이트 읽기 시도...
-> 읽기 성공: C0 DE C0 DE C0 DE C0 DE C0 DE C0 DE C0 DE C0 DE

[Step 2] Zone 0 (0x0000) 16바이트 쓰기 시도 (실패 기대)...
-> 쓰기 거부됨 (정상): 0x04
   (결과 분석: 칩이 잠겨있고 Read-only 정책이 잘 작동하고 있습니다.)
```
