# 예제 52: 잠금 후 인증 기반 쓰기 테스트

이 예제는 칩이 잠긴(`LOCKED`) 상태에서 권한 설정된 영역(Zone 1)에 인증을 거쳐 데이터를 쓰는 과정을 보여줍니다.

## 테스트 내용 (v2 업데이트)
1. **ManufacturingID 확인**: `0xF02A`에서 실제 ManID를 읽어와 인증 계산에 사용합니다.
2. **인증 수행 (Auth)**:
    *   **CCM Nonce**: 칩의 12바이트 Nonce + MacCount(0x01)를 합친 **13바이트** 구성을 사용합니다.
    *   **Usage (Param2)**: `0x0002`를 설정하여 쓰기 권한(`WriteOK`)을 명시적으로 요청합니다.
3. **인증 전/후 쓰기 비교**: 권한 획득 전 실패와 획득 후 성공을 비교 검증합니다.

## 실행 방법
```powershell
.\build.ps1 52 all
```

## 기대 결과
- [Step 1] 쓰기 실패 (`0x08` 등 액세스 에러)
- [Step 2] 인증 성공
- [Step 3] 데이터 기입 및 읽기 확인 성공
